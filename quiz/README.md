# Quiz questions — how to edit

> **Heads up — the app now reads questions from `data/quizzes.json`, not from
> these files directly.** These per-subject files are kept as a friendly way to
> edit. After changing anything here, recompile the manifest:
> ```bash
> node tools/build-quizzes.js
> ```
> Prefer editing one file? Edit `data/quizzes.json` directly instead — same
> questions, one file. See `data/README.md` for the format and for pushing
> updates live via Firebase.

Every subject has its own folder, and every folder has one file per class:

```
quiz/
  hindi/    class1.js  class2.js  class3.js  class4.js  class5.js
  english/  class1.js  ...
  gk/       ...
  ... (14 subjects in total)
```

`class1.js` = Class 1 questions, `class2.js` = Class 2, and so on up to Class 5.

## To change the questions for a subject + class

1. Open the matching file, e.g. `quiz/science/class3.js`, in any text editor.
2. Each `{ ... }` line is one question:

   ```js
   { question: "What do plants need to make food?", answer: "Sunlight", options: ["Sunlight", "Milk", "Sand", "Plastic"] },
   ```

3. Edit the text, add new lines, or delete lines you don't want.
4. **Save the file, then refresh `quiz2.html` in the browser.** Done — the quiz uses your new questions.

## Rules (keep these or a question will misbehave)

- Give **exactly 4 options**.
- The `answer` text must **exactly match** one of the 4 options (same spelling, same capitals).
- Keep everything in `"double quotes"`. If your text itself contains a `"`, write it as `\"`.
- Keep the comma at the end of each question line.

## Subjects that are NOT here (on purpose)

These 6 are generated by the quiz automatically (endless fresh questions), so they have no files to edit:

**Add & Subtract, Multiplication, Division, Mixed Math, Patterns, Reasoning.**

## Adding a brand-new class file

If you ever add, say, `quiz/gk/class6.js`, also add this line near the bottom of `quiz2.html`
(next to the other includes) so the page loads it:

```html
<script src="quiz/gk/class6.js"></script>
```
